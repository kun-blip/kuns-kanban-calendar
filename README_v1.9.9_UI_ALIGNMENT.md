# KUN’S KANBAN CALENDAR v1.9.9

## 변경 사항

- 일정 편집의 상태 선택지는 `소프트런칭` / `라이브` 두 가지입니다. 기존 내부 상태 코드 `todo`/`doing`은 유지해 저장 데이터와의 호환성을 보장합니다.
- 달력의 상태 필터는 `전체 상태`와 두 상태로 표시합니다. 과거 완료 일정은 삭제하지 않고 기존 상태로 유지되며, 완료된 일정을 열어 다른 필드만 수정해도 명시적으로 상태를 변경하지 않는 한 완료 상태가 보존됩니다.
- 공유 일정 편집에서도 동일한 두 가지 선택지를 표시하며, 기존 완료 상태를 보존합니다.
- 작업 체크리스트·자세한 메모 및 일정 초대/공유의 접기/펼치기 화살표를 텍스트 글리프 대신 CSS 기하학적 chevron으로 교체해 세로 중앙 정렬합니다.
- **v1.9.9의 팝업 패치노트 문구는 요청대로 v1.9.8의 제목·설명·세 항목을 그대로 재사용**하며 버전 번호만 자동으로 v1.9.9로 표시됩니다.

## CMD 배포

1. Windows Git 프로젝트 폴더(기존 `kuns-kanban-calendar`)에 PATCH ZIP의 내용물을 그대로 풀어 덮어씁니다. ZIP 내부 최상위 폴더 없이 배치되어 있습니다.
2. `RUN_v1.9.9_TESTS_CMD.bat`을 실행하여 테스트 통과를 확인합니다.
3. `PUBLISH_v1.9.9_CMD.bat`을 실행하여 `PUBLISH`를 대문자로 입력합니다.
4. GitHub Actions의 `windows-release`, `macOS Universal DMG` 빌드 성공과 GitHub Release의 v1.9.9 등록을 확인합니다.
5. 설치된 앱의 업데이트 후 동작/패치노트를 수동 검수합니다.

**주의:** CMD 배포 스크립트는 Git 저장소의 `main` 브랜치에서 실행해야 하며 기존 태그가 있으면 중단합니다. 테스트 통과가 Windows GUI 수동 검수를 의미하지는 않습니다.

## 회귀 검수

- 일정 열기: 상태 선택지 두 개만 보이는지 확인.
- 기존 완료 일정 편집: 상태를 만지지 않고 메모만 변경한 뒤 완료 표시가 유지되는지 확인.
- 기존 완료 일정의 상태를 소프트런칭/라이브로 명시적으로 변경하면 반영되는지 확인.
- 자세한 메모 및 체크리스트의 chevron이 세로 중앙에 놓이는지 확인.
- 공유창의 접기/펼치기 항목이 가운데 정렬되며, 이전의 동료 그룹 초대 기능이 정상인지 확인.
- v1.9.8에서 v1.9.9로 업그레이드 후 패치노트 팝업이 한 번 뜨고, 1.9.8과 내용이 동일한지 확인.
