- **02. 일정 태그 및 타임라인 편집 개선** — `@태그` 생성, 태그 컬러 설정, 타임라인 우클릭 편집과 날짜 드래그 생성을 지원해요.

1. 공유 일정 원격 GET 캐시 방지, 30초 간격 재조회 및 앱 복귀/포커스/온라인 상태 갱신, 수동 새로고침 버튼. 원격 저장 직후 오래된 데이터로 덮어쓰기 방지.
2. 그레이(#808895) 타임라인 컬러, 날짜 드래그로 일정 기간 선택, 기존 일정 우클릭 색상 변경 및 삭제.

4. 테마 스위치의 '라이트 모드'/'다크 모드' 텍스트 추가, 오늘 버튼 클릭 시 실제 현재 날짜 재계산.
5. 버전 업데이트 및 업데이트 후 1회 표시되는 v1.9.11 패치노트 등록. 이전 버전 패치노트 유지.

## 권장 CMD 배포 방법
1. 기존 프로젝트 폴더를 **백업**합니다. `v1.9.10`이 현재 GitHub `main` 기준임을 확인합니다.
2. `KUNS_KANBAN_CALENDAR_v1.9.11_PATCH.zip`의 **내용**을 기존 프로젝트 폴더에 풀어 덮어씁니다. **ZIP 안에 폴더를 한 겹 더 만들지 마세요.**
3. `RUN_v1.9.11_TESTS_CMD.bat` 실행 후 모든 테스트 성공 확인.
4. `PUBLISH_v1.9.11_CMD.bat` 실행. 표시된 Git 상태를 검토한 후 `PUBLISH` 입력 (실제 GitHub 푸시/태그 생성).
5. GitHub Actions의 Windows/macOS 잡이 성공하고 GitHub Release에 설치 파일이 있는지 확인.
6. Windows 업데이트와 Mac 수동 DMG 다운로드 후 실제 앱에서 UI를 확인합니다.

### 주의
- **테스트 통과는 실제 Mac 두 사용자 간 공유 일정 반영 속도를 보장하지 않습니다.** Mac에서 원격 일정 변경 직후 새로고침으로 정상 반영되는지 꼭 확인하세요.
- Mac 설치 파일은 **서명/공증되지 않은 테스트 DMG**입니다. Mac 자동 설치 업데이트를 새로 구현하지 않았습니다.
- 스크립트는 GitHub `main` 및 `v1.9.11` 태그를 변경합니다. GitHub에 배포하려는 경우에만 실행합니다.
- 패치 ZIP만 프로젝트에 덮어씌워도 PC에 설치된 앱은 즉시 바뀌지 않습니다. 설치 앱은 빌드 완료 후 업데이트해야 합니다.
