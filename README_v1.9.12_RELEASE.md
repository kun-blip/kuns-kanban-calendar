# KUN'S KANBAN CALENDAR v1.9.12 — 자유 입력형 일정 태그

## 이번 업데이트 (사용자 확정 문구)
**자유 입력형 일정 태그 지원**
`@` 뒤에 원하는 단어를 입력해 자유롭게 태그를 생성할 수 있습니다. 고정 태그 추천 목록을 제거하고 입력 편의성을 개선했습니다.

## 변경 내용
- 제목 입력 시 `@검수`, `@출시`, `@빌드` 등 세 항목만 제시하던 자동 추천 목록 제거
- `@마케팅`, `@QA테스트`, `@회의` 등 자유로운 태그명 사용 가능
- 공백 입력 또는 제목 입력란에서 벗어날 때 태그 생성, 저장 시 마지막 `@단어` 확정
- 기존 태그 컬러 변경 및 공유 일정 관련 동작 유지
- 한글 IME 입력 완료 전 잘못 변환되는 문제 대응
- 기존 `[검수]` 등 수동 접두어의 호환성 유지
- 일정당 최대 8개, 태그명 최대 20자(한글/영문/숫자/언더바/하이픈)

## 설치 (Windows CMD)
1. **반드시 v1.9.11 소스 프로젝트**를 준비하고, 수정 패치 ZIP을 프로젝트 루트에 압축 해제하여 `renderer/`, `desktop/`, `test/`와 *.bat 파일을 덮어씁니다.
2. 가능하면 기존 소스는 백업한 다음 진행합니다. `dist/`와 `node_modules/`는 덮어쓰지 않습니다.
3. 다음 파일을 더블클릭하거나 CMD에서 실행합니다.

```bat
cd /d C:\Users\master\Documents\GitHub\kuns-kanban-calendar
RUN_v1.9.12_TESTS_CMD.bat
```

4. 테스트 통과 시 `PUBLISH_v1.9.12_CMD.bat` 실행 후 소스 변경과 버전을 확인합니다.
5. 실제 배포를 원할 때만 **PUBLISH**를 입력하세요. 그러면 커밋 → `main` 푸시 → 태그 `v1.9.12` 푸시가 실행되어 GitHub Actions를 시작합니다.
6. GitHub Actions Windows/macOS 빌드, Releases 자산 및 실제 Windows/macOS 앱의 업데이트/패치노트 표시를 확인하세요.

## 검증 범위
- Node.js `npm test`: UI 코드 구조, 태그 파싱, 기존 공유/업데이트 회귀 자동 테스트
- 앱을 직접 조작하는 Windows/macOS 실기기 클릭 검증 및 배포 결과 확인은 별도

## 주의
- 배포 전까지 실제 GitHub 태그/릴리스는 생성되지 않습니다.
- 패치 ZIP은 프로젝트 폴더에 **직접 덮어쓰는 상대 경로 구조**입니다. 압축 내 루트 폴더를 추가로 중첩하지 마세요.
- 프로젝트 내 다른 미커밋 변경이 있다면 커밋 대상에 포함되는지 꼭 확인하세요.
