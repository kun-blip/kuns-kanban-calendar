# KUN'S KANBAN CALENDAR v1.9.18 배포 안내

## 업데이트 내용 (최종 승인 문구)

1. **최신 버전 업데이트 개선**
   중간 버전을 거치지 않고 가장 최근에 배포된 버전을 다시 확인하도록 개선했어요.
2. **공유 일정 표시 간소화**
   타임라인의 공유자 표시는 제거하고, 공유 상세 화면에서만 확인할 수 있도록 정리했어요.

## v1.9.17 프로젝트에 적용하는 방법 (Windows / CMD)

1. 기존 Git 저장소 프로젝트 폴더를 백업합니다. 설치된 앱 폴더가 아니라 소스 폴더를 사용하세요.
2. `KUNS_KANBAN_CALENDAR_v1.9.18_PATCH.zip`을 원본 프로젝트 폴더에 압축 해제하고 기존 파일을 덮어씁니다.
3. `RUN_v1.9.18_TESTS_CMD.bat`을 실행해 테스트 통과를 확인합니다.
4. `PUBLISH_v1.9.18_CMD.bat`을 실행하고 표시된 파일 목록을 검토한 뒤 `PUBLISH`를 입력합니다.
5. GitHub Actions 성공뿐 아니라 GitHub Releases의 v1.9.18 설치 자산 및 `latest.yml` 게시 여부를 확인합니다.
6. Windows 설치형 앱에서 업데이트를 확인하고, 기존 테스트 공유 일정의 작성자·초대 권한도 유지되는지 점검합니다.

## 중요한 주의

- v1.9.15~v1.9.17에 설치된 **이전 업데이트 확인 코드에는 개선 내용이 아직 없습니다**. 해당 사용자는 첫 전환 시 한 차례 중간 버전 업데이트가 나타날 수도 있어요. v1.9.18 설치 이후부터 개선 로직이 적용됩니다.
- 업데이트는 기존 데이터베이스의 일정·초대·권한을 삭제하거나 재생성하지 않습니다.
- 저장된 공유 일정 작성자 정보는 데이터로 유지되며, 타임라인 및 위젯에서 표시만 제거합니다. 공유 상세의 '공유한 사람:' 표시는 유지합니다.
- 자동 테스트는 Electron 설치형 앱과 동료 PC의 실제 업데이트 흐름을 완전히 대체하지 않습니다. 실사용 검수가 필요합니다.
- macOS는 기존 정책대로 새 버전 알림 후 GitHub에서 DMG를 수동 설치합니다.
- 오류가 있으면 `git reset --hard`나 `git clean -fd`를 실행하지 마세요.

## 검수 권장 항목

- v1.9.15에서 최신 v1.9.18이 보이는지 (개선된 업데이트 코드 설치 이후 동작 포함)
- 예전 설치 파일을 이미 내려받은 경우 더 최신 버전을 다시 확인하는지
- 타임라인·위젯에는 공유자 이름이 없고, 공유 상세에는 있는지
- v1.9.16 테스트 공유 일정의 작성자와 보기/편집 권한이 유지되는지
