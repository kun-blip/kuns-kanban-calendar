# KUN'S KANBAN CALENDAR v1.9.6 — 화면 정리와 동료 수정 패치

## 이전 버전
- 기준: v1.9.5 (2026-10-29 빌드)
- 데이터/DB 마이그레이션: 없음. 기존 일정·동료·공유 권한을 유지합니다.

## 수정 내용
1. **동료 수정 / 그룹 이름 변경**: Electron에서 지원하지 않는 `window.prompt()`를 제거. 앱 안에서 닉네임·이메일·소속 그룹을 한 번에 편집하고 저장/취소. 기존 그룹 자동 완성 목록 제공. 자동 초대/자동 수락 체크는 유지됩니다.
2. **일정 공유 화면 정리**: `기존 초대 코드 수락`, `공유된 일정 (N)`, `동료 관리 (N)` 섹션을 클릭해서 접거나 펼치기. 기본값은 접힘이며, 펼침 상태는 앱이 공유 데이터를 갱신할 때도 유지됩니다. 받은 초대함은 중요한 알림이므로 계속 표시됩니다. 초대 코드 링크가 들어오면 해당 섹션은 자동으로 펼쳐집니다.
3. **초대 수락 활성화**: 코드 입력칸이 비어 있으면 수락 버튼이 회색/비활성. 입력하면 활성화. 코드 유효성 검사와 수락은 기존 서버 기능 그대로 사용합니다.
4. **일정 생성·수정**: `작업 진행 상태` → `상태`, `예정` → `예정 - 소프트런칭`, `진행` → `진행 - 라이브`. `완료` 유지. *저장 값 `todo`, `doing`, `done`은 그대로라 기존 일정과 필터, 공유 기능이 호환됩니다.*
5. **양식 공간 절약**: `작업 체크리스트`와 `자세한 메모` 접기/펼치기. 기존 작성 데이터는 접힌 상태에서도 보존·저장되며 체크 항목 개수와 메모 요약이 제목에 표시됩니다.
6. **순서 변경**: 관련 링크 입력/열기를 동료 초대 위로 이동.
7. **피드백 응답**: Google Sheets에 전송 **성공한 경우에만** 피드백 창을 자동으로 닫고 하단 알림 표시: `또 피드백을 주셨군요? 빠른 시일내에 반영 업데이트 하도록하겠습니다 감사합니다♥`. 전송 실패 시 창과 작성 내용은 그대로 유지합니다.
