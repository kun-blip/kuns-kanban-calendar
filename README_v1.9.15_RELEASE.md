# KUN'S KANBAN CALENDAR v1.9.15 — 태그 UI / 주말 일정 표시 개선

기준 버전: **v1.9.14**. 이번 릴리스는 이전 개발 검토용 태그 UI + 주말 표시 통합 패치를 정식 배포 패키지로 전환한 것입니다.

## 승인된 패치노트 (앱 내 자동 표시)

1. **태그 관리 UI 개선** — 저장된 태그 목록을 접고 펼칠 수 있으며, 원하는 태그를 클릭해 일정에 즉시 적용할 수 있어요.
2. **태그 컬러 설정 개선** — 태그 배경색과 글자색을 각각 설정하고 실시간 미리보기를 지원해요.
3. **주말 일정 표시 개선** — 토요일·일요일의 하루 일정도 캘린더에 표시돼요. 여러 날에 걸친 일정은 기존처럼 주말을 건너뛰어 표시됩니다.

## 동작 요약

- 태그 관리 목록은 기본적으로 접혀 있습니다. 펼친 목록에서 기존 태그를 클릭하면 일정에 바로 적용되고 목록은 다시 접힙니다.
- 태그 생성·수정 화면에 38×38px 정사각형 배경색 및 글자색 컬러칩, 실시간 태그 미리보기가 추가됩니다.
- 기존 태그의 텍스트 컬러가 없을 때 흰색을 사용해 이전 일정과의 호환성을 보존합니다.
- 토·일 **하루짜리** 일정은 캘린더 타임라인에 표시됩니다. **이틀 이상 이어지는 일정**의 타임라인은 주말을 건너뜁니다.
- 주말 포함 일정의 시작일·종료일, 공유 저장 값은 수정하지 않습니다.

## CMD 테스트 및 배포

1. 기존 GitHub 프로젝트의 **v1.9.14** 소스를 백업합니다.
2. `KUNS_KANBAN_CALENDAR_v1.9.15_PATCH.zip`을 원본 프로젝트 최상위에 덮어씁니다. `package.json`과 `renderer` 폴더가 같은 위치여야 합니다.
3. `RUN_v1.9.15_TESTS_CMD.bat`을 실행합니다. 테스트가 모두 통과해야 다음 단계로 진행합니다.
4. `PUBLISH_v1.9.15_CMD.bat` 실행 → 변경 파일 목록 확인 → `PUBLISH` 입력.
5. GitHub Actions의 Windows / Mac 빌드 성공과 v1.9.15 Release 파일을 확인합니다.

이미 Git에 등록 대기(staged) 중인 파일이 있으면 배포 스크립트가 중지됩니다. 파일 목록 확인: `git diff --cached --name-only`. 관련 없는 변경 사항은 반드시 검토하고, 해당 변경을 유지하면서 등록 대기만 해제할 때만 `git restore --staged .`를 사용하세요.

## 실사용 검수 항목

- 태그 관리 목록을 펼쳐 저장 태그 클릭 → 일정에 즉시 적용 및 목록 자동 접힘
- 배경색/텍스트색을 바꾸면 미리보기가 즉시 반영되는지
- 토요일 한 날짜만 지정해 만든 출시 일정이 보이는지
- 금요일~월요일 일정의 타임라인이 토·일을 건너뛰는지
- 일요일 시작/월요일 시작 달력과 Windows/macOS에서 동일하게 표시되는지

**자동 테스트는 실제 macOS 기기 테스트를 대체하지 않습니다.** GitHub에 코드를 게시하기 전까지는 앱 업데이트가 완료된 것이 아닙니다.
