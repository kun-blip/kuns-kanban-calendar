# KUN’S KANBAN CALENDAR — Windows v1.5.4 (v13)

## 변경 사항

이번 수정은 **시작 창 크기 / 일반 모드 복귀 동작만** 고쳤습니다.

- 프로그램을 완전히 종료하고 다시 실행하면 기본적으로 **일반 달력을 최대화하여 시작**합니다.
- Windows의 작업 표시줄과 DPI 배율에 따라 **현재 모니터의 사용 가능한 작업 영역**을 채웁니다. 고정 1400×1050으로 시작하지 않습니다.
- 위젯에서 `전체 달력 ↗`을 누르면 **동일한 최대화 일반 창**으로 전환합니다.
- 위젯은 기존처럼 **가로 580, 세로 최대 1120 논리 픽셀** 크기를 기준으로 열립니다.
- 앱이 트레이에 살아 있는데 프로그램 아이콘을 다시 실행한 경우에도 일반 달력으로 복귀하도록 연결했습니다.
- 저장된 마지막 위젯 모드 여부와 상관없이 **새 프로그램 실행은 일반 달력**에서 시작합니다.
- 데이터 형식, 일정, 메모, 게임 타이틀, 바로가기, 알림, 백업, 다크 모드는 건드리지 않았습니다.

## Windows 설치 / 업데이트

1. 기존 앱에서 `백업 메뉴 > 백업 저장`을 눌러 JSON 백업 파일을 보관합니다.
2. 시스템 트레이에서 기존 앱을 **완전히 종료**합니다. (창 X는 트레이로 숨김 처리될 수 있습니다.)
3. 압축을 모두 풀고 `BUILD_WINDOWS_APP.bat`을 실행합니다. Node.js LTS와 인터넷 연결이 필요합니다.
4. 빌드 후 `dist/KuunsKanbanCalendar-Setup-1.5.4-x64.exe`를 기존 프로그램 위에 설치합니다.
5. 프로그램 아이콘으로 새로 실행해 일반 캘린더의 창 크기를 확인합니다.

**유의:** 첨부 스크린샷은 모니터의 실제 픽셀 크기이며 Electron 창 크기는 Windows 배율을 반영한 논리 픽셀입니다. 따라서 사진의 숫자 픽셀을 그대로 지정하기보다는 일반 창을 최대화하여 화면 비율을 맞추는 방식을 사용했습니다. 앱을 수동으로 작게 바꾸는 것은 여전히 가능합니다.

이 ZIP은 Windows 설치 파일 자체가 아니라 설치용 EXE를 생성하는 전체 소스 프로젝트입니다. Windows 환경에서 실제 빌드 및 표시 여부를 추가 확인해야 합니다.
