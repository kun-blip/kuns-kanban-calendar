# KUN'S KANBAN CALENDAR v1.8.1 — 시작 요일 선택과 Todo 개선

## 포함된 기능

1. **주 시작 요일 선택**: 전체 달력 상단에 `주 시작: 일요일 / 월요일`을 선택할 수 있습니다. 월간·주간 타임라인과 위젯 미니 달력에 함께 반영됩니다. 기존 사용자는 기본값이 **일요일**이며, 선택 사항은 PC의 기존 앱 데이터에 저장됩니다.
2. **전체 달력 Daily Todo**: 오른쪽 사이드바 하단에 위젯의 Daily Todo를 동일한 리스트로 표시합니다. 양쪽 화면에서 추가·완료 체크·수정·삭제한 결과가 한 리스트에 저장됩니다.
3. **Todo 수정**: 각 Todo의 연필 `✎` 버튼으로 수정 시작 → `✓` 또는 Enter로 저장, `↶` 또는 Escape로 취소. 140자 제한, 빈 문자열 저장 불가.
4. **백업 호환**: 주 시작 설정이 JSON 백업에 포함되며, 예전 백업에 설정이 없어도 일요일을 기본값으로 복원합니다. 기존 이벤트, 메모, 링크, Todo 기록은 삭제하거나 초기화하지 않습니다.
5. **운영체제**: Windows용 NSIS/업데이트 및 Mac Universal DMG 빌드 설정은 v1.8.0 그대로 유지합니다. Mac은 여전히 서명되지 않은 시험판이고 자동 업데이트는 비활성화 상태입니다.

## 적용 및 배포

- 먼저 현재 캘린더의 **백업 저장** 기능으로 JSON 백업을 만들어 두세요.
- `KUNS_KANBAN_CALENDAR_v1.8.1_PATCH.zip` 내부 파일을 GitHub 프로젝트 **루트**에 복사하며 같은 파일을 덮어씁니다. `.git` 폴더는 건드리지 않습니다.
- GitHub Desktop에서 `Add week start choice and editable shared Todo v1.8.1`로 Commit → Push합니다.
- 최신 커밋에 `v1.8.1` 태그를 생성해 Push합니다. 새 버전 번호는 이미 반영되어 있으므로 `npm version` 명령을 다시 실행할 필요가 없습니다.
- GitHub Actions의 Windows 및 Mac 빌드를 확인하고 Releases에서 Windows EXE와 Mac DMG가 올라왔는지 점검합니다.

## 수동 검수 권장 사항

1. 전체 달력에서 일요일→월요일 전환 후, 2026년 11월의 첫 주와 요일 순서, 주간 보기 및 타임라인의 월~금 위치를 확인합니다.
2. 위젯 모드로 전환하여 미니 달력도 월요일부터 시작하는지 확인합니다.
3. 전체 달력에서 Todo 작성 후 위젯에서 수정하고, 전체 달력으로 돌아와 수정 반영을 확인합니다. 완료 체크와 삭제도 반대 방향으로 확인합니다.
4. 앱을 완전히 종료하고 다시 실행해 주 시작 설정 및 수정된 Todo가 유지되는지 확인합니다.
5. 기존 JSON 백업 복원에서 투두 내용이 정상 복원되는지 확인합니다.

## 테스트 범위

- Node.js 자동 테스트 55개 통과 (주 시작 요일, 평일 타임라인 범위, Todo 수정 데이터, 기존 자동 업데이트/배포 코드 포함).
- HTML 구조 검사 통과.
- Chromium 자동 화면 테스트는 이 실행 환경의 브라우저 접근 제한으로 실행되지 않았습니다. Windows 앱 UI 및 실제 Mac 설치는 배포 후 수동 검수가 필요합니다.
