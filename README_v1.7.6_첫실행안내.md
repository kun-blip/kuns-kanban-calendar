# KUN'S KANBAN CALENDAR v1.7.6 — 첫 실행 환영 안내

- 첫 설치 사용자는 앱 첫 실행 시 로고와 중앙 정렬 환영 문구, 사용 방법을 확인합니다.
- 안내 제목: "안녕하세요 여러분, / 쿤스 칸반 캘린더에 오신 걸 / 환영합니다!"
- '캘린더 시작하기' 또는 닫기를 누르면 `welcome-complete.json`에 완료 여부를 저장합니다.
- 이미 `calendar-data.json`, `settings.json`, `reminders-fired.json`, 자동 백업 폴더가 있으면 기존 사용자로 간주하고 자동 팝업을 건너뜁니다.
- Windows 시작 시 트레이로만 실행했다면 캘린더 화면을 열 때 팝업을 보여줍니다.
- 우측 상단 '도움말' 버튼으로 언제든지 안내를 다시 볼 수 있습니다.
- 업데이트 알림은 첫 실행 안내를 닫은 뒤 표시되므로 두 모달이 겹치지 않습니다.
- 일정/메모의 저장 구조, Google Sheets 피드백 기능 및 업데이트 배포 흐름은 유지합니다.

## GitHub 배포

1. 기존 GitHub 프로젝트 폴더에 패치 파일을 폴더 구조 그대로 덮어씁니다.
2. GitHub Desktop에서 변경 목록을 확인하고 Commit → Push합니다.
3. 최신 커밋에 `v1.7.6` 태그를 만들어 Push합니다. 릴리스 EXE 및 `latest.yml` 확인 후 업데이트합니다.
4. 기존 PC에서 환영창이 자동으로 뜨지 않는지 확인하고, 도움말 버튼으로 수동 열기를 확인합니다.
5. 첫 설치 동작은 **별도 Windows 사용자 계정 / 깨끗한 테스트 환경**에서 확인합니다. 기존 일정 데이터 폴더를 삭제해서 시험하지 마세요.

## 현재 검증 범위

`npm test` 코드 테스트 통과. Windows 설치 및 새 사용자 프로필에서의 실제 팝업 동작은 설치 후 확인이 필요합니다.
