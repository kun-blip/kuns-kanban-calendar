# KUN'S KANBAN CALENDAR v1.9.10

## 변경된 기능

### Mac 새 버전 알림 및 다운로드 연결
- 기존 v1.9.9 코드에 포함된 GitHub Releases 버전 확인 기능을 유지하고, 업데이트 창의 다운로드 버튼 표기를 명확히 했습니다.
- 실행 후 약 4초에 버전을 확인하고, 이후 약 6시간마다 확인합니다. 새 버전 발견 시 앱 내 업데이트 창 및 블루닷으로 안내합니다.
- Mac에서 DMG를 받으면 사용자가 직접 앱을 교체합니다. Apple Developer Program 서명/공증 비용과 별개로 **이번 업데이트는 자동 설치를 제공하지 않습니다**.
- DMG가 릴리스에 아직 없다면 GitHub Releases 페이지를 열도록 안내합니다.

### 블루닷 적용 — 두 곳만
1. **업데이트 버튼**: 새 버전 사용 가능(Windows/Mac) 또는 Windows에서 다운로드가 완료된 때 표시. 현재 최신 버전이면 제거합니다.
2. **일정 공유 버튼**: 아직 수락 또는 거절되지 않은 받은 초대가 한 건 이상이면 표시. 초대를 처리해 목록이 비면 제거합니다. 화면을 열었다는 이유만으로 사라지지는 않습니다.

일반 일정이나 메모, 피드백 버튼은 상시 알림 과부하를 피하기 위해 표시하지 않습니다.

## 이번 패치노트 — v1.9.10
v1.9.9와 첫 두 항목 동일, 세 번째 항목만 변경:
1. 그룹 전체 일괄 초대
   - 동료 그룹을 선택하면 구성원 전체를 한 번에 일정에 초대할 수 있어요.
2. 그룹별 보기/편집 권한 설정
   - 초대하는 그룹마다 보기만 또는 편집 권한을 간편하게 설정할 수 있어요.
3. Mac 사용자 업데이트 안내
   - Mac 자동 설치 업데이트는 Apple 개발자 계정의 서명·공증 비용 문제로 현재 보류 중입니다. 이번 버전에서는 새 버전 알림과 GitHub 다운로드 안내 기능만 지원합니다.

## Windows CMD 배포
1. 기존 `kuns-kanban-calendar` GitHub 프로젝트 루트에 패치 ZIP의 **내용물**을 풀어 같은 이름의 파일을 덮어씁니다.
2. `RUN_v1.9.10_TESTS_CMD.bat` 실행 → 119개 자동 테스트 통과 확인.
3. `PUBLISH_v1.9.10_CMD.bat` 실행 → CMD에 `PUBLISH` 입력.
4. GitHub Actions에서 Windows/macOS 빌드 성공 확인.
5. 기존 Windows 앱 업데이트 및 Mac DMG 새 버전 안내를 각각 실제 기기에서 확인합니다.

## 수동 확인 시나리오
- 초대가 0건이면 `일정 공유` 블루닷 숨김 → 동료에게 새 초대를 받아 미처리 1건 이상이면 표시 → 수락/거절하면 사라짐.
- GitHub에 더 높은 버전이 있을 때 `업데이트` 버튼에 블루닷과 새 버전 안내 표시 → 업데이트 후 사라짐.
- Mac 신버전 안내에서 `Mac 다운로드 페이지 열기` 클릭 → 해당 GitHub DMG 또는 최신 Releases 페이지 열림. 자동 설치는 시도하지 않음.
- 첫 업데이트 실행 때 v1.9.10 패치노트가 한 번만 자동 표시되며, 업데이트 메뉴에서 다시 열 수 있음.

## 상태
- Node 자동 테스트: 119개 통과 / 0개 실패.
- 실제 Windows 및 Mac 앱에서의 수동 테스트, GitHub 게시/빌드는 별도로 확인이 필요합니다.
