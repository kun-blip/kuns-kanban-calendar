# KUN'S KANBAN CALENDAR v1.9.19 업데이트 / CMD 배포 안내

**기준 소스**: v1.9.18. 이 패치는 이전에 배포한 소스 코드 폴더에 적용하는 파일입니다. Windows 앱 설치 폴더에 압축을 해제하면 안 됩니다.

## 확정된 업데이트 패치노트

1. **팀 공용 스티커 라이브러리 추가** — 동료들이 직접 스티커를 업로드하고 함께 사용할 수 있어요.
2. **캘린더 스티커 기능 추가** — 원하는 날짜에 스티커를 붙여 동료들과 공유할 수 있어요.
3. **일정 리액션 기능 추가** — 공유 일정에 스티커로 반응하고 서로의 리액션을 확인할 수 있어요.

## 구현 범위

- 기존 앱 로그인 계정을 사용해 PNG, WebP, GIF(2MB 이하)를 공용 스티커 라이브러리에 업로드/검색/재사용할 수 있습니다.
- 달력 날짜에 스티커를 붙이면 같은 서버를 사용하는 로그인 동료에게도 표시됩니다.
- 공유 일정 상세 화면에서 스티커 리액션을 붙이거나 취소할 수 있습니다. 개인 전용 일정은 리액션 대상이 아닙니다.
- 라이브러리 스티커 삭제는 업로더만, 자신의 날짜/일정 스티커 삭제는 붙인 사람만 할 수 있습니다.
- **공유 범위**는 별도 팀 관리 시스템이 아니라 **앱에 로그인 가능한 전체 계정**입니다.
- 기존 공유 일정과 초대 권한, 로컬 일정 데이터는 수정하지 않습니다.

## 서버 적용 상태 (중복 적용하지 마세요)

2026-11-03에 연결된 Supabase `kuns-kanban-calendar` 프로젝트에 아래 리소스를 **이미 추가했습니다**.

- `public.team_stickers`, `public.team_sticker_marks` (RLS 사용)
- 비공개 스토리지 버킷 `team-calendar-stickers`
- 등록/열람/삭제에 필요한 로그인 및 소유권 정책

`supabase/migrations/20261103180000_team_stickers.sql`은 **서버 구성 기록/다른 DB에 적용할 때 검토용**입니다. 기존 연결된 서버에서 다시 실행하지 마세요. `PUBLISH_v1.9.19_CMD.bat`은 이 SQL을 서버에 실행하지 않습니다.

## CMD 배포

1. GitHub 원본 프로젝트 폴더(예: `C:\Users\master\Documents\GitHub\kuns-kanban-calendar`)를 엽니다.
2. `KUNS_KANBAN_CALENDAR_v1.9.19_PATCH.zip` 안의 파일을 프로젝트 루트에 덮어씁니다.
3. `RUN_v1.9.19_TESTS_CMD.bat` 실행. 오류 없이 테스트가 통과하는지 확인합니다.
4. `PUBLISH_v1.9.19_CMD.bat` 실행. 변경 파일을 검토하고 안내가 나오면 `PUBLISH`를 대문자로 입력합니다.
5. GitHub Actions에서 Windows 및 macOS 빌드가 성공하고 GitHub Releases에 v1.9.19가 게시됐는지 확인합니다.

**주의**: 과거 `PUBLISH_v1.9.18_CMD.bat`을 다시 실행하면 `Local v1.9.18 tag already exists` 오류가 발생합니다. 반드시 **v1.9.19** 스크립트를 실행하세요. `git reset --hard`, `git clean -fd`는 사용하지 마세요.

## 검수 체크

- Windows/Mac의 로그인 계정으로 PNG/WebP/GIF 업로드 후 다른 계정에서 공용 목록에 나타나는지
- 해당 이미지가 날짜에 붙고 다른 PC에서도 표시되는지
- 공유 일정을 열어 리액션을 붙이고, 다른 참여자에게 수량과 작성자가 보이는지
- 자신이 붙인 스티커만 제거할 수 있는지, 타인의 스티커 삭제가 막히는지
- 기존 공유 일정·초대 권한·업데이트·일반 일정 기능이 정상인지를 확인합니다.

**자동 테스트는 기능을 모의 환경에서 검증한 것**이며, 실제 Windows/Mac 양쪽 앱의 업로드·동기화 클릭 검수는 별도로 필요합니다. GitHub 배포는 사용자 PC에서 배포 스크립트를 실행하기 전까지 완료되지 않습니다.
