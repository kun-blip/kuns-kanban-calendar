# KUN'S KANBAN CALENDAR v1.9.3 — 주말 숨김 복원 / 공유 일정 삭제

## 변경 사항
- v1.9.2에서 추가한 토·일 일정 칩 표시를 제거했습니다. 기존처럼 월~금 타임라인은 유지됩니다. 토·일로만 지정한 일정은 타임라인에는 표시되지 않습니다.
- v1.9.2에서 개선한 **작성자 공유 일정 서버 fallback 표시**는 그대로 유지합니다.
- 상단 **일정 공유 → 공유된 일정** 목록의 **작성자 일정**에 `일정 삭제` 버튼을 추가했습니다.
- `관리/보기`로 열린 작성자 상세에서도 `일정 삭제 (내 PC + 공유)`를 선택할 수 있습니다.
- 삭제 전에 대상·영향 범위를 확인합니다. 서버에서 **본인 소유 일정** 삭제가 성공한 경우에만 **현재 PC의 동일한 원본 일정**을 로컬에서도 제거하고 저장합니다. 다른 개인 일정/메모/투두는 건드리지 않습니다.
- 다른 사람의 공유 일정에는 `일정 삭제`를 제공하지 않습니다. 받은 일정은 기존처럼 `공유 일정 제거(나가기)`로만 처리합니다.
- 기존 `이 일정 공유 중단`은 그대로 유지됩니다. **공유 중단은 내 PC의 원본 일정을 보존**합니다.

## 배포 전 / 후 확인
1. 중요 일정은 JSON 백업을 저장하세요. 삭제는 되돌리기 지원이 없습니다.
2. 기존 GitHub 저장소 루트에 패치를 덮어쓰고 v1.9.3 태그로 배포하세요.
3. 토요일 단독 이벤트가 메인 **타임라인에 보이지 않는지** 확인하세요.
4. `일정 공유 → 공유된 일정`에서 주말 단독 이벤트를 찾아 `일정 삭제` → 확인을 누르세요.
5. 공유 목록에서 없어지고, 재실행 후에도 동일 이벤트가 사라지는지 확인하세요.
6. 다른 사람 계정의 공유 목록에서도 해당 항목이 제거되는지 확인하세요.
7. 평일·주말에 걸친 기존 일정의 평일 부분, 주 시작 요일 설정, 다른 개인 일정, 피드백, Windows 자동 업데이트, macOS 빌드는 그대로 유지되는지 검수하세요.

**주의:** 이 기능은 **현재 PC에 있는 본인 로컬 원본**을 제거합니다. 같은 사용자 계정의 다른 PC에 저장된 기존 개인 로컬 원본이 있다면 그 사본은 별도로 정리해야 합니다. `일정 공유 중단`과 `일정 삭제`의 차이를 꼭 확인하세요.
